# Réseau des Comoriens de Toulouse — inscription

Formulaire d'inscription à l'annuaire de la communauté comorienne de Toulouse, et schéma de la base de données (Supabase).

- `inscription.html` : le formulaire (mode démo tant que `config.js` est vide : rien n'est enregistré).
- `supabase/schema.sql` : tables, sécurité et vue publique de l'annuaire.

À fusionner plus tard avec le site du réseau.
